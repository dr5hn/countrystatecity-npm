# Project scope and session ownership

- This project/session owns the JavaScript and TypeScript npm packages in `dr5hn/countrystatecity-npm`.
- Python/PyPI work in `dr5hn/countrystatecity-pypi` belongs to a separate session. Do not change or test that repository, merge its PRs, publish its packages, or watch its workflows unless the user explicitly assigns that work to this session.
- A general request about "packages" or "the ecosystem" does not transfer work owned by another session. Keep the work within this npm project and report any cross-project dependency for the owning session.
- Reading the upstream `dr5hn/countries-states-cities-database` releases, schemas, and export files is allowed when needed to check npm compatibility.
- Before taking work in another ecosystem repository, establish that the user has explicitly assigned it here. Do not duplicate another session's work.
